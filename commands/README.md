Relay, task and msg work through the Relay tools of the service when they are available, and on the mind's Markdown records otherwise; absorb writes preferences. Evolve updates the base and attached agents, pylon configures team state, and swarm reports units, tasks and messages through the shared engine. Uninstall removes what was installed on this machine, through the shared engine's dry run and kept-file reporting, and protocol runs a strict sequence of steps for a routine or a loop. Migrate reads the rules, memories and notes an agent or a repository already holds and writes them into the mind's own records, leaving every original untouched. Every command that needs the unit locates it as the Locate section of [rules.md](../rules.md) says.
