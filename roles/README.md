One markdown file per role, fourteen: six general roles and eight presets. Each of the six works on a machine with a shell: the Executor and the Incubator in one folder, the Overlord as the lead of a squad, one environment or the chats of one repository, the Overseer across every project of the mind, the Adjutant on the requests of the person, with or without a repository, and Genesis on the mind itself. The eight presets, UX Designer, UI Designer, Writer, Game Designer, Security Consultant, QA, Code Reviewer and Product Manager, each do one kind of work in one project and read the knowledge module that matches it. A role file holds only what is its own; the start, work and exit every role shares, and the rule of one session per unit, are in [rules.md](../rules.md). The folder `genesis/` holds the setup steps Genesis reads while setup is not done, and is never installed as a command.
