One markdown file per role, fourteen: six general roles and eight presets. Each of the six works on a machine with a shell: the Executor and the Incubator in one folder, the Overlord as the lead of a squad, one environment or the chats of one repository, the Overseer across every project of the mind, the Adjutant on the requests of the user, with or without a repository, and Genesis on the mind itself. The Overseer, the Incubator and Genesis take one session per unit: a second session of the same unit stops at its Start. The Executor, the Overlord and the Adjutant can be in several at once, each under a numbered unit. The eight presets, UX Designer, UI Designer, Writer, Game Designer, Security Consultant, QA, Code Reviewer and Product Manager, each do one kind of work in one project, read the knowledge module that matches it, and take a numbered unit when their unit is already in, like the Executor.
