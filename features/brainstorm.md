# /brainstorm

Mind: {{mind}}
Argument: <topic>

Start: Locate in `rules.md` of the mind above.

## Steps

1. Open `brainstorm/<topic>.md` in the project's folder of the mind, or at the root of `user/` for a topic of no project, and create it when it does not exist. The file holds only the open questions, in one Open section.
2. The person tells the vision. Ask one question per message, through the client's native question tool when it has one.
3. Draft a piece of text only after a yes on its substance, show it, and write it only after a yes on the text. Drafted text follows the impersonal style.
4. Agreed text leaves the brainstorm file in the turn it is agreed, into its home:
   - On a product topic, the writer of the product document (the seat of the project, or the coordinator for a family or a project with no seat) writes it into the product document.
   - The coordinator, on a project with a seat, writes it as a brief Fact with its `(product: <section>)` pointer and sends the seat the `Product decision` note that `files.md` defines.
   - Any other unit sends the agreed text to that writer in one Relay note.
   - On a topic that is not a product topic, it goes into the document the topic is about, named with the person.
5. An answered question leaves Open. When Open is empty, the file is deleted; a file that an earlier session created is deleted only after the person's yes.

## End

- Stops when the person ends the topic or Open is empty.
- Reports the decisions taken in the session, each with the file it was written to, and the questions still open.
